# Аким на 5 часов

Интерактивный симулятор с локальным сервером AI-анализа для Astana Innovations. Данные районов и стоимость мероприятий синтетические; модель не является прогнозом или официальной оценкой города.

## Запуск

Нужен Node.js 22 или новее. Дополнительных зависимостей нет, `npm install` не требуется.
Из папки с `package.json`, `server.cjs` и `.env` запустите:

```powershell
node server.cjs
```

Откройте http://127.0.0.1:3000. Эквивалентная команда — `npm start`; если PowerShell блокирует `npm.ps1`, используйте `npm.cmd start`.
Выберите пять допустимых решений и нажмите **«Получить AI-анализ»**. Кнопка отправляет один запрос; при изменении сценария старый анализ сбрасывается. Запросы к OpenAI оплачиваются по тарифу вашего API-проекта.

Без сервера можно открыть `dist/index.html`: расчёт и базовое объяснение работают офлайн, AI-анализ недоступен.

## Настройка OpenAI API

Существующий `.env` с ключом перезаписывать не нужно. Если файла ещё нет, скопируйте `.env.example` в `.env` рядом с `server.cjs` и задайте:

```dotenv
OPENAI_API_KEY=ваш_ключ
OPENAI_MODEL=gpt-6-luna
PORT=3000
```

`OPENAI_MODEL` должен содержать идентификатор модели, доступной вашему API-проекту. После изменения `.env` перезапустите сервер (Ctrl+C, затем `node server.cjs`). Наличие ключа не гарантирует доступ к модели или достаточную квоту.

Сервер загружает `.env` относительно своего файла. Уже заданные переменные окружения имеют приоритет. Ключ не включается в HTML, ответы или журналы; `.env` исключён из Git и недоступен по HTTP.

`POST /api/analyze` принимает `{ "decisions": [{ "id": "M7", "district": "Нура" }, ...] }` (ровно пять решений). Сервер проверяет сценарий, самостоятельно рассчитывает показатели и вызывает [OpenAI Responses API](https://developers.openai.com/api/docs/guides/text). Передаются синтетические данные: решения, стоимость, Score, дельты, отдельные эффекты и синергии. Используется `store: false`. Клиентские Score и произвольные инструкции не используются.

LLM объясняет готовые результаты и предлагает качественные рекомендации. Числа в интерфейсе берутся только из модели; текст LLM может содержать ошибки и не меняет расчёт. При ошибке сети, ключа, модели, квоты или тайм-ауте интерфейс показывает причину; базовое объяснение сохраняется.

Сервер слушает только `127.0.0.1`, отклоняет запросы с других сайтов и разрешает один одновременный AI-запрос с интервалом минимум 3 секунды. Это локальный режим: публичное размещение потребует авторизации пользователей и лимитов на пользователя.

## Проверка

```powershell
node --test tests/*.test.cjs
```

Также доступны `npm test` / `npm.cmd test`. Тесты не читают `.env` и не вызывают платный API: проверяют контрольные баллы, валидацию, серверный расчёт, закрытый доступ к файлам конфигурации, ошибки провайдера, тайм-ауты и сброс устаревшего AI-ответа.

## Сценарий

Выберите ровно пять разных мероприятий из каталога 14 мер. Для районных мер укажите один из пяти районов. Бюджет — 100 условных единиц, не более двух мер из одного направления. Запрещены сочетания M1+M3 в любых районах, M4+M7 и M5+M13 в одном районе. Невалидный набор не получает итогового балла; интерфейс показывает причину. Изменение любого решения пересчитывает показатели и объяснение.

## Расчёт

Исходные значения десяти показателей для пяти районов, доли населения, эффекты, цены и лаги заданы в `dist/city-model.js` как открытые массивы `districts`, `measures`, `keys`, `weights`. Горизонт — 8 кварталов. Эффект каждой меры умножается на `(8 − lag) / 8`; общегородские меры действуют во всех районах. Фиксированные синергии M1+M2, M10+M12, M5+M6 добавляются после эффектов в районе первой меры. Затем значения ограничиваются диапазоном 0–100.

`D_d = Σ_k w_k · I'_dk`; `D_avg = Σ_d pop_d · D_d`; `Score = 0.7 · D_avg + 0.3 · min(D_d) − N_crit`, где `N_crit` — число показателей строго ниже 40. Остаток бюджета не влияет на балл. Экранные объяснения строятся из рассчитанных дельт, а не генерируют новые числа. Базовое объяснение детерминированное; дополнительный AI-анализ запускается по кнопке через сервер.

Контрольные значения: базовый Score `52.5577` (на экране `52.56`). Набор M7/Нура, M8/Нура, M10/Нура, M12/город, M5/Сарыарка стоит 95 и даёт `56.5431` (на экране `56.54`).

## Устройство

- `dist/index.html` — интерфейс и отображение расчёта.
- `dist/city-model.js` — общие данные, чистая функция `compute` и валидатор `validate` для браузера и сервера.
- `dist/ai-ui.js` — запрос AI-анализа, статусы и отмена устаревших ответов.
- `server.cjs` — локальный HTTP-сервер, загрузка `.env`, проверка сценария и вызов OpenAI.
- `tests/` — автоматические проверки без внешнего API.

При поддержке браузером WebMCP доступен инструмент `set_city_scenario` с общим валидатором. Ошибочный сценарий, включая неизвестный район, отклоняется до изменения состояния.
