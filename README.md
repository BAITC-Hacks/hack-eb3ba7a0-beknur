# Аким на 5 часов

Статический интерактивный симулятор для Astana Innovations. Данные районов и стоимость мероприятий синтетические; модель не является прогнозом или официальной оценкой города.

## Запуск

Откройте `dist/index.html` в современном браузере. Сборка, сервер, API-ключи и зависимости не требуются. Для локальной раздачи по HTTP: `python3 -m http.server 8000 --directory dist`.

## Сценарий

Выберите ровно пять разных мероприятий из каталога 14 мер. Для районных мер укажите один из пяти районов. Бюджет — 100 условных единиц, не более двух мер из одного направления. Запрещены сочетания M1+M3 в любых районах, M4+M7 и M5+M13 в одном районе. Невалидный набор не получает итогового балла; интерфейс показывает причину. Изменение любого решения пересчитывает показатели и объяснение.

## Расчёт

Исходные значения десяти показателей для пяти районов, доли населения, эффекты, цены и лаги заданы в `dist/index.html` как открытые массивы `districts`, `measures`, `keys`, `weights`. Горизонт — 8 кварталов. Эффект каждой меры умножается на `(8 − lag) / 8`; общегородские меры действуют во всех районах. Фиксированные синергии M1+M2, M10+M12, M5+M6 добавляются после эффектов в районе первой меры. Затем значения ограничиваются диапазоном 0–100.

`D_d = Σ_k w_k · I'_dk`; `D_avg = Σ_d pop_d · D_d`; `Score = 0.7 · D_avg + 0.3 · min(D_d) − N_crit`, где `N_crit` — число показателей строго ниже 40. Остаток бюджета не влияет на балл. Экранные объяснения строятся из рассчитанных дельт, а не генерируют новые числа. В этой версии текстовый аналитический слой детерминированный; внешняя LLM не подключена.

Контрольные значения: базовый Score `52.5577` (на экране `52.56`). Набор M7/Нура, M8/Нура, M10/Нура, M12/город, M5/Сарыарка стоит 95 и даёт `56.5431` (на экране `56.54`).

## Устройство

Один HTML-файл содержит интерфейс, данные, валидатор и чистую функцию `compute`. Это позволяет воспроизвести результат без сетевых сервисов. При поддержке браузером WebMCP доступен инструмент `set_city_scenario` с теми же правилами проверки. Для дальнейшего развития можно вынести данные в версионированный набор, добавить сравнение сценариев и подключить LLM исключительно к объяснению уже рассчитанных дельт.
