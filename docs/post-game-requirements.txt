==================================================
POST-GAME AI REPORT — ОБЯЗАТЕЛЬНО
==================================================

После завершения каждой игры система ОБЯЗАТЕЛЬНО
должна автоматически формировать персональный
AI Post-Game Report для игрока.

Игра считается полностью завершённой только после
формирования результата и AI-анализа.

На странице результата пользователь должен увидеть:

🤖 AI POST-GAME ANALYSIS

--------------------------------------------------
1. ИТОГ ИГРЫ
--------------------------------------------------

Показать:

- название города;
- режим игры;
- дату и время;
- количество игроков;
- место игрока;
- Astana Quality of Life Score;
- Baseline Score;
- изменение Score;
- использованный бюджет;
- оставшийся бюджет;
- выбранные 5 решений.

Например:

Astana Quality of Life Score
61.7

Baseline
52.56

Improvement
+9.14

Budget
95 / 100

Rank
2 / 8

--------------------------------------------------
2. ЧТО ИГРОК СДЕЛАЛ ПРАВИЛЬНО
--------------------------------------------------

AI ОБЯЗАТЕЛЬНО должен сформировать раздел:

"Что вы сделали правильно"

AI должен определить наиболее эффективные
решения игрока.

Каждый вывод должен быть основан на реальных
данных scoring engine.

Например:

✓ Выбор M10 улучшил показатели безопасности
  Нуры.

✓ M10 + M12 активировали синергию.

✓ Выбранные мероприятия позволили повысить
  минимальный показатель проблемного района.

AI должен объяснять:

- какое решение было принято;
- на какой район оно повлияло;
- какие показатели изменились;
- почему это было эффективно.

AI НЕ ДОЛЖЕН придумывать эффекты.

--------------------------------------------------
3. ЧТО ИГРОК СДЕЛАЛ НЕ ТАК
--------------------------------------------------

AI ОБЯЗАТЕЛЬНО должен сформировать раздел:

"Что можно было сделать лучше"

Анализировать:

- оставшиеся слабые показатели;
- районы, которые получили мало улучшений;
- неиспользованный потенциал бюджета;
- упущенные синергии;
- альтернативные мероприятия;
- критические показатели;
- неэффективное распределение ресурсов.

ВАЖНО:

Не нужно искусственно придумывать ошибки.

Если стратегия не содержит очевидных ошибок,
AI должен честно написать:

"Критических ошибок в выбранной стратегии
не обнаружено."

Но при этом может указать возможные улучшения.

--------------------------------------------------
4. АНАЛИЗ РАЙОНОВ
--------------------------------------------------

AI должен анализировать все районы:

Есиль
Алматы
Сарыарка
Байконур
Нура

Для каждого показать:

Before
After
Delta

и краткое объяснение.

Например:

Нура

S1:
38 → 48
+10

AI:
"Социальная инфраструктура Нуры улучшилась
после выбора M7..."

--------------------------------------------------
5. АНАЛИЗ 5 РЕШЕНИЙ
--------------------------------------------------

Для каждого выбранного решения:

- название;
- стоимость;
- район;
- направление;
- фактический эффект;
- изменённые показатели;
- вклад в стратегию.

Пример:

M7 — Школа + детсад
Район: Нура
Стоимость: 24

Эффект:
S1 + ...

AI explanation:
"..."

--------------------------------------------------
6. КОМПРОМИССЫ
--------------------------------------------------

AI должен объяснить Trade-offs.

Например:

"Большая часть бюджета была направлена
на социальную инфраструктуру Нуры.
Это улучшило S1, однако оставило меньше
ресурсов для экологических мероприятий."

AI должен объяснять не только положительные,
но и отрицательные последствия стратегии.

--------------------------------------------------
7. ОСНОВНЫЕ РИСКИ
--------------------------------------------------

AI должен определить:

- слабые районы;
- слабые показатели;
- критические значения;
- потенциальные проблемы;
- последствия текущего распределения бюджета.

--------------------------------------------------
8. ЧТО МОЖНО БЫЛО СДЕЛАТЬ ЛУЧШЕ
--------------------------------------------------

AI должен предложить альтернативную стратегию.

Например:

"Вместо M4 можно было рассмотреть M7,
что позволило бы..."

Но рекомендация должна учитывать:

- бюджет;
- стоимость;
- существующие решения;
- ограничения;
- несовместимости;
- доступные мероприятия;
- реальные эффекты.

AI НЕ ДОЛЖЕН рекомендовать невозможные комбинации.

--------------------------------------------------
9. ФИНАЛЬНОЕ AI SUMMARY
--------------------------------------------------

В конце создать краткое заключение:

"Ваша стратегия была ориентирована на..."

Заключение должно содержать:

- главную стратегию игрока;
- основные достижения;
- основные недостатки;
- главный trade-off;
- рекомендации на следующую игру.

--------------------------------------------------
10. AI НЕ СЧИТАЕТ МАТЕМАТИКУ
--------------------------------------------------

КРИТИЧЕСКОЕ ПРАВИЛО:

LLM НЕ рассчитывает Score.

LLM НЕ рассчитывает стоимость.

LLM НЕ рассчитывает эффекты.

LLM НЕ изменяет game state.

Все числа приходят из deterministic
SCORING ENGINE.

AI получает готовый JSON:

{
  "game_id": "...",
  "city": "...",
  "mode": "...",

  "baseline_score": 52.56,
  "final_score": 61.7,
  "score_delta": 9.14,

  "rank": 2,
  "players_count": 8,

  "budget": {
    "initial": 100,
    "spent": 95,
    "remaining": 5
  },

  "selected_measures": [],

  "districts": {},

  "measure_contributions": [],

  "synergies": [],

  "critical_indicators": [],

  "validation": {
    "valid": true,
    "violations": []
  }
}

AI использует только эти данные.

PDF REPORT
==================================================

Создавать профессиональный PDF-отчёт.

Название:

"Аким на 5 часов
AI Post-Game Report"

Структура PDF:

1. Title Page
2. Game Overview
3. Final Score
4. Budget
5. Selected Decisions
6. District Performance
7. Before / After Indicators
8. What You Did Right
9. What You Did Wrong
10. Trade-offs
11. Risks
12. AI Recommendations
13. Final AI Summary
14. Technical Score Breakdown

Добавить:

- таблицы;
- графики;
- progress bars;
- before/after comparison;
- Score;
- district comparison.

PDF должен быть читаемым и выглядеть как
официальный аналитический отчёт.

Не делать просто экспорт HTML страницы.

WORD REPORT

Структура:

Title
Game Information
Score

Incorrect Decisions / Improvements
Trade-offs
Risks
Recommendations
AI Summary

DOCX должен нормально открываться в Microsoft Word.

--------------------------------------------------
REPORT STORAGE
--------------------------------------------------

После завершения игры:

1. GameResult сохраняется в БД.
2. AI Analysis сохраняется в БД.
3. Пользователь может снова открыть игру
   через Game History.
4. Пользователь может повторно скачать
   PDF/DOCX/JSON.

Не требовать повторного запуска AI для скачивания
уже созданного отчёта.

==================================================
ACCEPTANCE CRITERIA
==================================================

После завершения игры пользователь ОБЯЗАТЕЛЬНО
должен получить:

1. Final Score
2. Score comparison with baseline
3. Selected decisions
4. District before/after
5. AI Summary
6. "Что вы сделали правильно"
7. "Что вы сделали не так"
8. Trade-offs
9. Risks
10. Recommendations
11. Download PDF
12. Download Word
13. Download JSON

Без этих элементов Post-Game Flow считается
НЕЗАВЕРШЁННЫМ.
